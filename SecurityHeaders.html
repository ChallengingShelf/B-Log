Top of the class. A+ security headers

Themes: Web Security | HTTP Headers | Cloudflare | CSP | free wins

HamiltonHacks October 2026

Good news! hamiltonhacks.com now gets an A+ on securityheaders.com. Not an academic achievement or any real form of validation but we’ll take it. Just a bit of tinkering in Cloudflare and the site is more secure. I immediately don’t like that phrase “more secure”.

What am I on about this time?

Every time you visit a website, the server sends back the page plus a bit of hidden info called headers.

These headers are the instructions that tell a browser how to handle the site safely. Only ever connect over HTTPS, only run code from places I trust, do not let other websites hide me inside theirs blah blah blah. The browser does the real enforcing, the website just has to ask.

Introducing SecurityHeaders[.]com

This is a nifty little website that checks this stuff for you. You put in a web address and it reads the headers which that site sends back and then you get a grade back. Just like school. From F to A+

It does it really quickly and for all your favourite sites !!! Go on check your bank, yknow just for funsies.

What did I tell cloudflare to do?

  • Strict-Transport-Security (HSTS) - always use HTTPS, never plain old HTTP
  • Content-Security-Policy (CSP) - the bouncer. Only scripts, styles and images from my approved list get
  • X-Frame-Options - nobody can load my site inside an invisible frame on theirs to trick you into clicking things (clickjacking)
  • X-Content-Type-Options - stops the browser guessing what a file is. A picture is a picture, let’s call a spade a spade.
  • Referrer-Policy - when you click a link off my site, the next site doesn't get the full address you came from
  • Permissions-Policy - no camera, microphone, location or payments. None of that nonsense
  • Cross-Origin-Opener-Policy - keeps my pages separate from any tabs they open.

How’s that then?

The site is hosted somewhere which doesn’t let me set my own headers :(( but Cloudflare sits on top of that which adds headers to every response with a ‘Transform Rule’. HSTS is quite simply a toggle in the SSL / TLS settings.

HSTS in Cloudflare's SSL / TLS settings

Top tip: roll out the CSP as Content-Security-Policy-Report-Only first. The browser just logs anything it WOULD have been blocked instead of ACTUALLY blocking it, so you can make sure nothing blows up before going ahead. That got me an A grade and then enforcing it got the A+. Congraduations.

It’s a pretty interesting process and fairly straightforward so why not do it? It doesn’t do any harm. Obviously it’s not suddenly unhackable, it’s just a very niche nice little bit of protection. Also, there is actually nothing of real value on this site so there’s nothing really to protect, but good practice and all that.
